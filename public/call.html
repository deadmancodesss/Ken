What a call actually does

Same tools, different mouth

Nothing on this page is a second agent. The microphone streams into one open call, that speech goes through the same tools the Talk page uses, and the answer comes back as audio you can interrupt by talking over it. The transcript stays on screen so you can check a number before you act on it.

you speak→the model closes the sentence→memory answers first→the answer is spoken
1

What the pickers do on a live call

A live call hears whatever language you speak in and answers in it, so the three pickers below govern the turn by turn path that runs when the server has no live key. On that path the first sets the language the microphone listens for, the second lists the voices this browser has for it, the slider sets how fast it talks, and all three are remembered for next time. Audition says one sentence so you can hear it before a call.

2

The ribbon is your real voice

Four curves drift against each other and their height comes from the microphone, so it swells when you do and settles when you stop. Nothing on it runs on a timer, and when the agent speaks each word pushes a swell through it.

3

A payment is never signed by voice

If the answer needs money, the call stops and points you at the Pay page, where your own wallet has to approve it.

4

A misheard name is not the wrong person

A microphone writes Sana as Sauna often enough to matter. Reading memory corrects the one letter and says the stored name back to you. Moving money refuses the correction and asks for an address, because a guess there spends real USDC on the wrong stranger.
