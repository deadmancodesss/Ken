How it started

A smaller, stranger bet

The first commit is dated 3 November 2026 and it is called Total Recall. The idea was narrow. A wallet agent should not read the chain every time you ask the same question. It should remember, and when it does not know, it should buy exactly one fact.

The first build was voice only. Then the surfaces multiplied: a text chat, a live call, a monthly limit, a request link with a QR, a statement, a paid note sold over x402. They all had to share one wallet and one memory, or the product would be six demos in a trench coat.

By 10 November it had a mainnet default, a seller process with its own wallet and ledger, 31 test suites and two videos. The name changed from Total Recall to Ken in the middle. The bet did not.

Nine things that broke

The bugs that changed the design

None of these are hypothetical. Each one is in the git history, and each one changed either a screen or a guard.

01

USDC with no SUI for gas

The first mainnet transfer assumed the fee came from SUI. A wallet can hold USDC and no SUI at all. Sui can move USDC from the address balance with a zero-fee transfer, so the builder tries the ordinary shape first and rebuilds the gasless shape only when SUI is missing. If neither fits, the page names the missing fee.

fixed
02

Invalid input before the popup

An older extension read the newer address balance and answered Invalid input before it opened. The page now catches that exact refusal and says the wallet is too old, that nothing was signed, and that no money moved.

fixed
03

The payment that was remembered twice

One settled transfer appeared twice in memory. Walrus has no delete verb, so the write carries an idempotency key and the read collapses duplicates. The store will not forget, so the fix is at both ends.

fixed
04

The mainnet key that refused

The agent's own key can sign on testnet. On mainnet it throws. That refusal is the design: the only key allowed to move real money is the one inside the browser wallet.

guard
05

Render wiped the room

The free instance loses its disk on a cold start. Wallet sessions now come back from a signed cookie and the seat rebuilds. Chat history still sits in a local SQLite file that a redeploy can erase. Walrus is the durable record.

partly solved
06

The network switch left the seat behind

Changing the ledger with a chat open could leave the seat reading the other network. The seat is now scoped to the network, and the transcript reloads when the switch moves.

fixed
07

The model picked a different tool

Two identical runs chose different tools. The model is not deterministic. The tests now assert on the numbers in the answer, not the tool name, and the prompts name the exact read window.

mitigated
08

The generated button turned to soup

Flow made beautiful motion, then turned every small UI label into mush. Product screens in the demo are real captures. Generated footage only carries the story.

worked around
09

Inbound money was invisible

Tatum's address history links the signer, so money arriving at your address did not show up. Inbound transfers are now read from the counterparty's side of the history. The MONEY IN column on the statement is the proof.

fixed
The drawings

A homemade image generator, in one command

Every drawing on this site came from a sentence. npm run plate sends that sentence to Cloudflare Workers AI with a locked style preamble, then pushes the paper to white so the drawing sits on the page without a frame.

The preamble names the palette before the scene: paper, brown-black ink, clay, moss, brick. No blue. No text. The same two people appear in every drawing, so the site reads as one book instead of a pile of stock art.

Models are listed by shape, not by brand. The flux-2 family wants multipart, the older models want JSON, and the step field changes name. The script sniffs the returned container because half the models answer with JPEG bytes behind a PNG filename.

The keyer is what makes it a site rather than a gallery. It lifts the paper to white, or keys it to transparency for the plates that move. A transformed parent would bring the white rectangle back, so the static plates never animate.

The rest of the resources were hunted one at a time. The Tatum Sui GraphQL gateway, the Walrus memory SDK, the x402 v2 spec, the gasless stablecoin shape, and a system font stack so no page waits on a webfont. The vendor marks are the only borrowed images on the site. The other pages draw them in ink, this page keeps their own color, small icons included.

The demo

How a 2:06 storyboard became a 1:19 cut

The storyboard was two minutes and six seconds: 46 seconds of story, 72 seconds of product, 8 seconds of close. The product demo that shipped is 1:19. The walkthrough is 4:17 and has no cuts.

The first plan was to generate the whole thing. Flow produced short motion shots with a consistent look, but it could not hold a UI. Keyframes morphed into each other instead of cutting, small labels turned into soup, and every attempt at a button looked like a button drawn from a description.

So the division became simple. Generated shots carry the story. Real captures carry the product. The 1320x960 UI crops in the edit are the same screens in the gallery above, recorded on the real build.

The second video exists because a polished demo can hide a hesitation. The walkthrough is one pass from end to end, with the waits left in. If the agent thinks for four seconds, you watch it think.

The brainstorming was mostly about what not to show. Every feature wanted a shot. The cut kept the loop: a question, a memory, a payment, a receipt. Everything else became a page on this site.
