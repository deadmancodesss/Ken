Ask it out loud, keep the paper

This is the same data the agent answers from. It reads the chain through Tatum for the amounts and Walrus for who each address is, then sets them on one card you can save, print or post.

Amounts read from chain. Names and notes read from memory. Nothing here was written by a model.

Why the card is typeset instead of generated

Every image model we can reach draws convincing paper and unreliable digits. A statement that gets a total wrong by forty cents is worse than no statement, because the one claim this product makes is that its numbers came from the chain.

So the layout is real vector text set from the tool output, which means the same file prints at any size, exports as a picture for sharing, and carries the exact figures the agent just spoke. The only thing a model touches here is the sentence it says out loud.
