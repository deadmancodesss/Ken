You say a sentence, not a query

“Who do I pay most?” or “has Dev paid me back?”. The model turns that into one or two tool calls, and you never choose a tool yourself.

It reads your memory first, always

Walrus holds every name you have given it and every fact it has already bought. That read is the slow step and the free one, and it happens on Mainnet rather than in a database.

costs nothing

The chain is read only when memory is not enough

Tatum answers amounts, dates and counterparties. Inbound money never appears in your own transaction list, so Ken reads the other side of each transfer to find it.

Money

Nothing leaves until your own wallet signs

The agent can prepare a payment and then it has to stop. Say the coin, USDC or SUI, and code builds that exact transfer. The ticket keeps one coin slot you can switch before signing, and the number stays the same. This server holds the bytes and never holds your key, so refusing is always available and always final.

The paid index

Three questions, one wall, one price before you sign

x402 is not a way to sell this app. It is a way to buy a fact the buyer cannot get for free, and this build sells exactly three of them through one charging wall. Each one has a price before anything is signed, each one is checked on chain before the answer is released, and each one is free forever after, because the answer goes to Walrus the moment it is paid for.

Paper

Ask it out loud, keep the card

Say "give me a report of what I have been paying people" and the same tool calls that answer you out loud set this card. The amounts come from the chain and the names come from memory. No model wrote any of it, because a statement with a wrong total is worse than no statement.

no model

Every figure is read from Tatum or from Walrus. The card is drawn by the server from those reads, so it can be checked line by line and printed without a screenshot.
