It reads your memory first, always

Walrus holds every name you have given it and every fact it has already bought. That read is the slow step and the free one, and it happens on Mainnet rather than in a database.

The chain is read only when memory is not enough

Tatum answers amounts, dates and counterparties. Inbound money never appears in your own transaction list, so the agent reads the other side of each transfer to find it.

When an address is unknown, the agent is charged for naming it. That is the x402 half of the product: a price is quoted, you sign it, the answer is released, and the fact is written down.
