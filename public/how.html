The whole path

Your sentence crosses four systems before it is answered

Two of them are slow and one of them costs money. The design is entirely about how seldom each one gets touched, and this page is the honest version of that, including the numbers that are not flattering.

What each part is

Four systems, and what the product would be without each

Tatum · Sui GraphQL

The eyes

Reads balances, transfers and counterparties on mainnet and testnet with one key per network. Without it you would type addresses in and the agent would be describing your imagination.

Walrus · MemWal

The memory

One namespace per wallet, holding plain sentences about people. Without it every question re-reads a rate limited chain, and the agent never learns anything about your life.

Gemini

The brain and the mouth

Turns a sentence into a tool call and a tool result into two spoken sentences. Without it you have a block explorer with extra steps.

Sui USDC · x402

The market

A 402 handshake priced in testnet USDC, verified by a chain read the payer cannot fake. Without it the agent has no way to find out something it does not already know.

The memory, exactly

A line of prose, and the address that owns it

Nothing about this is clever storage. A fact is a sentence in your namespace, and the name is the part a later question can find. That is what makes the second asking free and what makes the memory portable between the app, the call and anything else that reads the same namespace.

Why it is split per wallet

Your people are not another person's people. The namespace is derived from the wallet you are speaking for, so connecting your own wallet gives you your own memory and the demo story keeps its notes somewhere else. Switching on the masthead chip is the only way to move between them.

The safety rules

Five things this build refuses to do

No key of yours on the server

The page prepares transaction bytes and waits. Money moves only after your wallet signs, and refusing to sign leaves nothing behind.

No memory written on a claim

A browser reporting a digest is not evidence. The transaction is re-read from the chain and the debit and the credit both have to match.

No second payment for one answer

A receipt is spent the moment it releases a fact, and a payment that moved without a fact is journalled and offered back on the next ask.

No silent pricing

The amount, the asset and the payout address arrive in the same 402 reply, before anything is signed, and the running total is in the masthead on every page.

No invented people

If memory has nothing and the index has nothing, the agent says it does not know. A confident wrong name is worse than an honest blank.

What is still rough

The parts a judge should not be sold on

Stated plainly

  • The brain runs on a free tier and it does show. Routing is a live Gemini model making real function calls against these same twelve tools, and it picks the tool, reads the result and answers in plain sentences. What is not production is the capacity. Measured today, one tool turn came back in 26 seconds and another in 218, and every model in the text chain also returned 503 "high demand" for a stretch before recovering on its own. A room full of judges asking at once will hit this.
  • The model's voice arrives after the sentence, not during it. /speak is genuinely calling a text to speech model, and a short sentence takes about two seconds from Fish Audio and about five from Gemini, so the ribbon waits for the whole line. Nothing is spoken until the whole answer exists. A live call is the other case: there the model streams audio as it talks and you can interrupt it, and it stops.
  • Three voices can answer, and the page says which one spoke. Fish Audio is tried first because it measured faster and is limited by five requests at once rather than by a count of sentences. HeyGen is second, through OpenRouter, and is switched off right now because the credential in this server's config is a web session token rather than an API key, which the page says out loud instead of pretending. Gemini is last and covers any sentence the others refuse. Gemini's own sentence allowance is observed rather than published, so read the count as a floor and not a spec. Measured on this key today, it returns 429 for speech while the live call socket still hands up in half a second.
  • Cadence needs days, not code. "About every three days" is measured from real transfers on different days, and the seeder will not pay the same person twice in one UTC day. Until it has run for a few days the honest answer is "most recently today".
  • Real microphone audio has not been exercised. The capture path, the transcript and the spoken reply are built, and the call page holds a session, but every demo so far has been typed.
  • No wallet extension was installed for these runs. The signature leg was driven by a script that does what an extension does with the same bytes, so the handshake is proven and the popup is not.
  • Memory has no delete. Walrus exposes remember and recall, so removing a name means writing a corrected line and living with the old one in the namespace. A receipt is filed under its transaction, so the same payment cannot be stored twice, but one that is already wrong stays wrong.
  • Warm answers still take a couple of seconds. The recall round trip is the floor, which is why the interface shows what it is doing rather than pretending.

everything above is a known limit with a route, not a claim that it already works
